System roles are created with the company schema — they can be read but never edited or deleted. Custom roles are yours to change, and a role cannot be removed while anyone still holds it.

Per-user access grants

Extra permissions on top of a user’s role. The corresponding tabs stay hidden for the user until you grant access here.

User Role Extra grants Actions

Ordered by employee code, which is also the login username. Saving replaces a user’s whole extra-grant set — it is not additive — and writes an ACCESS_GRANTED row to the audit log.
